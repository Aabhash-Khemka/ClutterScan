# ClutterScan Algorithms

This directory contains the machine learning, computer vision, and heuristic algorithms powering ClutterScan.

## Pipeline Architecture

- `preprocessing/`: Scripts and utilities for normalizing images, color balancing, edge extraction, and feature preparation.
- `detection/`: Models and pipelines for detecting objects, clutter hotspots, and surface boundaries.
- `classification/`: Classification models to categorize clutter into item categories, urgency levels, or material types.
- `resolution/`: Heuristics and generative logic to produce actionable cleanup and organization recommendations.
